Sito15Maggio Skyline Travel
Skyline Travel è un sito web moderno e responsive dedicato ai viaggi, sviluppato interamente con HTML, CSS e JavaScript.

Il progetto permette agli utenti di esplorare destinazioni, visualizzare offerte realistiche e simulare la prenotazione di viaggi personalizzati.

Funzionalità principali

Mappa interattiva
- Mappa del mondo responsive
- Punti interattivi sulle principali città
- Popup dinamici con immagini delle destinazioni
- Hover migliorato con animazioni fluide

Destinazioni immersive
Ogni città include:
- immagine ad alta qualità
- video hover automatico
- descrizione della destinazione
- prezzo realistico del viaggio

Destinazioni disponibili:
- New York
- Parigi
- Londra
- Roma
- Tokyo
- Dubai
- Bali
- Madrid
- Rio de Janeiro
- Sharm El Sheikh

Sistema di prenotazione realistico
La pagina prenotazione permette di scegliere:
- stato di partenza
- destinazione
- data del viaggio
- orario
- numero di persone
- mezzo di trasporto
- tipo di alloggio
- budget massimo
- stile di viaggio

Il sistema genera automaticamente:
- offerte realistiche
- prezzi dinamici
- opzioni differenti in base alle preferenze

Registrazione utente
Prima della prenotazione l’utente deve registrarsi.
Validazioni implementate:
- email valida
- numero di telefono corretto
- password obbligatoria
- controllo dei campi obbligatori tramite JavaScript

Messaggi dinamici:
- errori in rosso
- conferme in verde

Responsive Design
Il sito è responsive:
- desktop
- tablet
- smartphone

Include:
- hamburger menu mobile
- top button
- layout adattivo
- galleria responsive
- mappa responsive

Tecnologie utilizzate
- HTML5
- CSS3
- JavaScript
